# Notes for AI agents

To add or change knowledge base entries, follow [AI-GUIDE.md](AI-GUIDE.md). It defines the entry structure, the writing rules and the ways to send entries.

To change the website itself: content lives in `entries/` and `topics/`, the site is built by `site/build.mjs` (`npm install && npm run build`), and the save service is in `worker/`. See README.md.
